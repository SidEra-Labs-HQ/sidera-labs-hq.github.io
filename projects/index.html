02Listing standard

What a project needs to appear here.

The same rules apply to every entry, including future ones.

Evidence

  • A public repository or a public demonstration that anyone can open.
  • A description that matches what the code actually does.
  • Stated limitations, written by the people who built it.

What is not listed

  • Private repositories, however promising.
  • Personal projects that belong to an individual and not to SidEra Labs.
  • Ideas, roadmaps and mock-ups without working code.
ConceptA written idea or design. Not listed as a project until something runs.
PrototypeRuns for a narrow case. Expect gaps, no support and breaking changes.
BetaWorks for its stated use, tested, with known limitations documented.
ProductionUsed for real work, maintained, with a defined way to report problems.
