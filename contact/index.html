Contact

One honest route.

SidEra Labs does not publish an email address, phone number or contact form. The public route is the GitHub organization.

Reach us through GitHub.

Use the SidEra Labs GitHub organization. For questions about a specific repository, open an issue in that repository. For corrections to this website, open an issue in the website repository.

SidEra Labs does not currently accept unsponsored collaboration or speaking requests, and no response time is promised.

Open the GitHub organization→

Useful to include

  • Which page or repository you are writing about.
  • What you expected and what you found.
  • A link or a minimal example if it is a technical issue.
  • For accessibility problems: the page, your browser and any assistive technology.

Please do not post private or sensitive information in a public issue.
